# Responsible Use

AD Attack Path Predictor is a defensive prioritization tool for lab, education, and authorized security assessment.

Use this project only when all of the following are true:

- You own the environment, or you have explicit written permission to analyze it.
- Collection data was obtained legally and in accordance with organizational policy.
- Results are used to reduce risk, improve detection, or support defensive research.
- No production exploitation is performed as part of this project.

Do not use this project to plan, enable, or optimize unauthorized intrusion.

The sample data in this repository is synthetic and does not describe a real organization. The authors and contributors provide no warranty and accept no responsibility for misuse.
